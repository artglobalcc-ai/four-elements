# Sandbox decisions approved in this chat

The current user's decisions supersede older conflicting exploration/combat examples.

- Together: leader records the route for the group. Tab cycles identities through physical slots,
  preserving character-owned inventory. Support Katara, Sokka, Aang, Toph, eventually Zuko.
- T opens manual split selection; up to four independent groups, including solo groups.
- R cycles selected groups. Unselected groups idle unless actively returning.
- Inventory E opens selected leader; Tab carousels only current group, allowing local transfers.
- Hold T requests fast-walking reunion over passable terrain. No teleport through blocked terrain.
- Story events may require the full story-available party (sandbox uses its five test actors).
- Sustained bending persists across control changes and expires with character concentration.
- Inventory pauses the ENTIRE world, including concentration, return travel, attacks and animations.
- Combat: faint full-battlefield grid only while choosing movement. Movement may be used before
  and after an attack within one allowance; keep future restrictions/character exceptions configurable.
- Start combat aftermath with water residue and scorch marks. Major structural damage is authored
  for selected encounters, not unrestricted destruction across all battles.
- Personal inventory: on-person quick access plus larger backpack; Pokemon organization with
  Stardew-style item presentation. Appa storage only near Appa/at camp.
- One integrated sandbox before building the world. User retains final map layout/art control.
- Use docs/02_Reference_Images and its captions; Avatar animated series guides game art identity.

Current milestone implements party controls, provisional personal storage, weapon equipment,
a reusable timed hit interaction and Katara's basic Water Manipulation. Combat/advanced bending/world saving,
Appa and final animation art remain future milestones. No combat rules are implemented by the
exploration club swing.

- Terrain-aware Space jump changes character height and supports designated ledges only. Chests, fire pits, containers and other props are not landing platforms. The sandbox low/high ledge course demonstrates this without replacing the original prototype controller.
