# Artwork workflow sandbox

Open art_workflow.tscn in Godot 4.7.2 and use Run Current Scene (F6).
The project main scene remains world.tscn.

This is a baseline copy of the village for testing presentation and artwork replacement.
It is not the proposed architecture vertical slice. Combat and traversal decisions remain pending.

IMPORTANT: Scripts, animation resources, textures and item definitions are currently shared
with the prototype. Changing those shared files changes both scenes. Duplicate only the
resources needed for an approved experiment into this sandbox before editing them.
Use new filenames and UIDs for copies. Never duplicate the prototype scene UID.
