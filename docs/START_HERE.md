## Reading and preservation notes

The top of each feature note summarizes **which game contributes what**. The rest contains full, verbatim excerpts of relevant pages from both source guides and embedded screenshots from the reference atlas. A page may appear in multiple notes intentionally: this ensures no inspiration is hidden in a different feature folder.

**Do not treat the source excerpts as newly reconciled rules.** Later decisions and unresolved issues are identified in the decisions note. The source PDFs and complete source Markdown files remain in `99_Original_Documents`.

### Obsidian setup

Open this folder as an Obsidian vault, or move `01_Features`, `02_Reference_Images`, `99_Original_Documents`, and `START_HERE.md` into your own vault. Obsidian wikilinks and image embeds should resolve within the same vault.
