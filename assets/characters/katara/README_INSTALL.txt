KATARA — TRANSPARENT PNG SPRITES FOR GODOT
40 RGBA PNG files (64 x 80): 8 idle and 32 walking frames.
These have transparent backgrounds; the dark sprite-sheet background was removed.
Preview against a checkerboard using PREVIEW_CHECKERBOARD.png.

INSTALL:
1. Back up res://assets/characters/katara/
2. Copy the contents of frames/ into res://assets/characters/katara/frames/
3. Copy katara_animations.tres into res://assets/characters/katara/
4. Reopen Godot. Your current animation names and katara.gd script remain unchanged.

Note: These are carefully masked extractions from an illustration, not individually hand-painted master sprites. Minor dark edge pixels may still require touchups in Aseprite or LibreSprite.
