FOUR ELEMENTS — KATARA STARTER SPRITES

40 transparent PNGs, each 24x32 native pixels. 8 unique facing directions, 1 idle + 4 walking frames each. 16 named animations in Godot SpriteFrames.

INSTALL:
1. Unzip.
2. In your Godot project, create assets/characters/katara/.
3. Copy ALL the files inside this package into assets/characters/katara/ (including the frames subfolder).
4. Select Katara > AnimatedSprite2D. In Inspector > Sprite Frames, choose Load, then assets/characters/katara/katara_animations.tres.
5. Set Animation to idle_down. Turn off Autoplay if you prefer.
6. Texture filtering should be Nearest (Project Settings).

Animations: idle_down, idle_down_right, idle_right, idle_up_right, idle_up, idle_up_left, idle_left, idle_down_left; corresponding walk_... animations.

ART NOTE: This is an original hand-pixelled prototype, not a pixel-perfect extraction of the earlier AI concept. It is designed to be structurally usable and deliberately simple at 24x32. We can improve likeness and refine movement timing after seeing it in-game.
